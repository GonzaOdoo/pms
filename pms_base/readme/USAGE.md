## Creating Your First Property

1.  Go to **Properties ‣ Properties** and click **New**.
2.  Fill in the property name, reference, address, timezone, and area.
3.  Assign an owner (a contact from your address book).
4.  Add tags and amenities as needed.
5.  Set the stage to **Available** once the property is ready.

## Properties

Navigate to **Properties ‣ Properties** to view and manage your property
portfolio. The list and Kanban views let you filter by stage, team,
owner, and tags. Use the search panel to filter by team directly from
the Kanban view.

Click on a property to open its form and access:

- **Information** tab: area, floor, number of rooms by type, amenities.
- **Chatter**: log notes and track changes.

## Rooms

If **Show Rooms** is enabled, navigate to **Properties ‣ Properties ‣
Rooms** to manage rooms within a property. Each room has a type,
capacity, area, floor, and room-specific amenities.

On the property's **Rooms** tab, define **Bookable Accommodation Types**
such as "Standard Double" or "Suite". Each type stores its occupancy,
bedroom and bathroom counts, area, and shared amenities. Link each
physical room to one of these types; room-specific capacity, area, floor,
and amenities can still be recorded on the physical room itself.

## Amenities

If **Show Amenities** is enabled, navigate to **Properties ‣
Configuration ‣ Amenities** to define amenities. Amenities are grouped
by type (Toiletries, Connectivity, Kitchen facilities, etc.) and can be
assigned to properties.

## Services

If **Show Services** is enabled, navigate to **Properties ‣
Configuration ‣ Services** to link service products to properties.
Services represent recurring or on-demand offerings such as internet
access, cleaning, or parking.

## Teams

If **Show Teams** is enabled, navigate to **Properties ‣ Teams** to
group properties by management team. The team Kanban dashboard shows a
property count button that opens the filtered property list for that
team.
